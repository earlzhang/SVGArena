关于 SVGArena

SVGArena 通过统一的提示词让各大模型生成 SVG 信息图，自动核验指令遵循度与渲染质量， 以静态画廊形式呈现各模型的 SVG 能力差异。

评测方法

  1. 使用 litellm 统一调用各模型 API，每个模型对同一内容生成 5 次
  2. 采样温度 0.8（考察输出波动与创意多样性），max_tokens 32768（放宽以不限制模型能力）
  3. 用 Playwright Chromium 渲染 SVG 为 PNG（与网页展示同引擎）
  4. 自动核验指令遵循度 + 渲染质量，满分由任务约束决定

评分标准

前提：SVG 合法且渲染成功，否则 0 分。满分 = 启用的 A 层数 + B 层 4 项。

指标判定条件类别分值
纯净输出响应恰好以 <svg 开头、</svg> 结尾，无围栏/前言/后记A · 任务特定1
比例合规viewBox 高宽比在 2.10~2.20 范围内（iPhone 全面屏比例约 2.16）A · 任务特定1
字体合规font-family 不含非 macOS 内置中文字体（如微软雅黑、思源黑体等）A · 任务特定1
浅色底PNG 边框区域众数色亮度 > 0.75A · 任务特定1
无溢出文字包围盒不超出 viewBox 边界，也不超出所在卡片矩形边界B · 通用1
无重叠文字元素两两包围盒重叠面积不超过较小元素的 20%B · 通用1
无遮挡文字未被图形元素（箭头、图标等）遮挡。像素级差分检测：渲染两次（含文字/隐藏文字），在文字核心区域检查图形硬边侵入，排除删除线等横贯设计元素B · 通用1
非空白墨迹率（非背景像素占比）在 2%~80% 之间B · 通用1

A 层（指令遵循度）：由 task.yaml 的 constraints 驱动，只有提示词中明确要求的约束才计入总分。换测试项目时自动适配。
B 层（渲染质量）：通用指标（无溢出 / 无重叠 / 无遮挡 / 非空白），任何 SVG 信息图都适用，始终计入总分。

渲染环境

  • 操作系统：macOS（Darwin 25.5.0）
  • 渲染引擎：Playwright Chromium（headless）
  • 设备像素比：2x（Retina）
  • 字体环境：macOS 系统内置字体（PingFang SC 等），未注入自定义字体

免责声明

本评测在 temperature 0.8 下进行 5 次采样，反映的是该参数下的典型表现而非模型最优水平。 评分仅衡量指令遵循度与客观渲染质量，不评判美观度与创意——后者请访问者在画廊中自行判断。
